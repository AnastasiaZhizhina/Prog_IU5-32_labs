# Лабораторная работа № 2 — ООП в Python

## Запуск

1. Создайте и активируйте виртуальное окружение.
2. Установите зависимости: `python -m pip install -r requirements.txt`
3. Запустите программу: `python main.py`
4. Запустите тесты: `python -m unittest -v`

В `main.py` замените `n = 5` на номер своего варианта.
